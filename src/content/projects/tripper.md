Tripper is a comprehensive e-commerce platform designed for travel experiences. Built with modern web technologies, it features a highly interactive and responsive interface that makes trip planning and booking seamless.

## Features

- **Authentication**: Log In & Sign Up flows for secure user access.
- **Search & Filter**: Find the perfect trip by destination, date, and price.
- **Wish List**: Save favorite trips for future reference.
- **Cart & Checkout**: A streamlined checkout process for booking trips.
- **Profile Setting**: Manage personal information and account details.
- **Order Management**: View past orders and detailed receipts.

## Technologies Used

- **Framework**: Vue 3 Composition API, Vue Router v4.x, Pinia
- **Backend**: Firebase v9 (Authentication, Database)
- **Styling**: Tailwind CSS, SCSS, Responsive Web Design (RWD)
- **Packages**: Vuelidate, VueUse, Vue Toastification, VCalender, Swiper, Heroicons

This project showcases full-stack capabilities, particularly focusing on front-end state management, routing, and responsive UI design.
